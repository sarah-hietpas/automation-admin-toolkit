# powershell-admin-toolkit
A collection of PowerShell scripts for Azure, Entra ID, Microsoft 365, AWS, Windows administration, security, and automation.

## Categories

- Azure
- Microsoft Entra ID
- Microsoft 365
- Active Directory
- AWS
- Power Platform
- Security
- General Utilities

## Requirements

Most scripts require PowerShell 7+.

Some scripts require modules including:

- Microsoft.Graph
- Az
- AWS.Tools
- Microsoft.PowerApps.Administration.PowerShell

## Disclaimer

These scripts are provided for educational and administrative purposes. Review and test scripts before running them in production environments.
